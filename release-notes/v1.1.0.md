# logforge 1.1.0

One function, added while pipeforge integrates.

## Added

`logforge::set_current(logger)` binds a logger to the calling thread without a
scope and returns whichever logger was bound before it:

```cpp
logforge::Logger *const previous = logforge::set_current(&element_logger);
/* ... */
logforge::set_current(previous);
```

`ScopedBinding` is now defined in terms of it, so the two can never disagree about
which slot they write to. The function exists for the two callers that cannot use a
scope -- a compatibility shim that has to keep a "set and hand back the previous
logger" signature, and a test that wants to leave the thread unbound.

## Compatibility

Nothing moved. A 1.0.0 consumer needs no edit, and no behaviour changed: the
binding a scope installs, and where `current()` looks, are the same as in 1.0.0.
