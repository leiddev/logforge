# logforge 1.3.0

One addition, for the program that keeps its logger name in configuration.

## `SpdlogBackend::Config::name`

```cpp
logforge::SpdlogBackend::Config config;
config.name = "xec";
```

The name is what spdlog's registry knows the logger by and what a pattern's `%n`
prints. It defaults to `"logforge"`, so nothing that does not set it changes.

Before this, the name was fixed at construction and spdlog offers no rename at any
version this backend supports, so a consumer with a configured logger name had to
build the `spdlog::logger` itself -- and lose the sink selection, the level table,
the `component` prefix and the no-sink fallback this class provides. An empty name
falls back to the default rather than producing a logger spdlog cannot identify.

Everything else is unchanged: the API frozen at 1.0.0, the header set, the CMake
package, the spdlog floor of 1.10.
